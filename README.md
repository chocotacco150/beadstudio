# 豆图 · 图片转拼豆图纸

完整的 React + TypeScript + Canvas 工作台。图片在浏览器本机处理，应用不需要登录、数据库、接口密钥或付费服务。

## 运行

Windows 可以直接双击 **启动工具.cmd**。当前工作目录已经安装依赖，会自动打开 `http://127.0.0.1:5173`，关闭终端或按 Ctrl+C 停止。

在其他环境需要 Node.js 22.12+，执行：

```sh
npm install
npm run dev
```

也可以使用 pnpm：`pnpm install`、`pnpm dev`。Vite 固定使用 5173 端口，已运行一个实例时请直接访问它，或先停止该实例。

```sh
npm run build   # TypeScript 检查 + 生产构建，输出 dist/
npm run preview
npm test        # 17 项核心行为、HTML 分享和 PDF 排版测试
```

`dist/` 可以部署到任意静态服务器。请通过 HTTP 打开，不要直接双击 dist/index.html；图片转换使用浏览器 Worker，直接打开本地 HTML 文件不支持。

## 发给朋友在本地运行

提供的 **拼豆工具-本地版-Windows.zip** 包含完整项目源码、生产构建、示例图片、色板、使用说明和 Windows x64 的 Node.js 运行时。将整个压缩包发给朋友即可；不需要开放网站访问权限。

1. 使用 Windows 的「全部解压」，不要在压缩包内直接运行。
2. 打开解压后的 `bead-studio` 文件夹，双击 **本地运行.cmd**。
3. 浏览器会自动打开 `http://127.0.0.1:5173`。若端口已被占用，自动选择附近可用端口，以启动窗口显示的地址为准。
4. 保持启动窗口打开；使用结束后关闭窗口或按 Ctrl+C。图纸请在页面中「保存项目」，下次「加载项目」继续编辑。

Windows 本地运行包无需安装 Node.js、npm 或开发依赖，也不需要联网、登录和管理员权限。建议使用近期版本的 Chrome 或 Edge。图片、转换、编辑、统计和导出都在朋友自己的电脑上执行；网站上的访问权限不影响本地版。

`src/` 是完整源码；`dist/` 是已编译好的应用；`scripts/local-server.mjs` 只读取 `dist/` 静态文件，监听本机回环地址，不接收图片上传。`runtime/` 仅在运行包中附带，不参与前端构建。修改源码后需安装开发依赖并重新执行 `npm run build`，再启动本地版；修改源文件不会直接改变已有的 `dist/`。

macOS / Linux 用户可使用同包源码与 `dist/`，安装适用于系统的 Node.js 22.12+ 后执行 `node scripts/local-server.mjs --open`。Windows 自带的 `runtime/node.exe` 不适用于这些系统。

运行包不包含 `.git/`、`.openai/`、部署凭据、开发缓存或测试截图。已保存的个人图纸 JSON 需要另行发送，源码包不会自动包含浏览器中正在编辑的图纸。

## 已实现

- PNG/JPG/WebP 拖拽与文件上传；拖动选区裁剪、百分比微调；原图对比。
- 默认使用带庭院背景的真实照片，128 格 / 32 色；保留像素插画示例，可分别体验两种转换方式。
- 32/48/64/96/128/192/256 格预设、自定义 1–512 行列、按原图/裁剪比例适配，最多 262,144 格。显示实际行列和 5 mm 拼豆的成品尺寸。
- 照片采用 3×区域采样、透明度加权平均、保留边缘的碎色简化及明暗对比调整；像素插画使用最近邻采样。照片有背景也能直接转换，较强简化减少复杂背景纹理。
- 可选去除边缘纯色背景：根据边缘主色，沿相近颜色连通区域去除，容差可调；不改变封闭区域。适合纯色纸张、白墙等背景，**不是复杂场景的 AI 主体识别**。复杂背景建议保留，配合裁剪突出主体。
- 根据 OKLab 感知色差匹配真实色板；加权选色限制 8/16/24/32 色；可选 Floyd–Steinberg 抖动，默认关闭。
- 透明采样像素的 alpha 小于 128 时视为空白；也可选择任意背景色，在去背景和采样后进行透明合成，再匹配色板。
- 画笔、橡皮擦、吸管、移动、滚轮和按钮缩放；快速拖绘连续补点；最多 50 步撤销重做，大图按 200 万历史格子预算自动保留较少步骤。
- 预览按视野和设备像素比实时重绘，放大后色号仍清晰，不会拉伸低清晰度全图位图；低缩放下仅显示每十格粗线，放大后显示细网格与色号。
- 网格/色号/坐标独立显示；每 10 格粗线，坐标标注 1、5、10…及边缘格子；点击色号选择画笔并高亮，再次点击取消高亮。
- 实时用量、总颗数、实际用色、尺寸和空白格；空白不计入用量。
- 「本图纸所需色号」集中列出全部使用中的色号，按编号排列、显示种类总数；点击色号高亮，一键复制完整清单。随绘制、替色、撤销及项目加载实时更新，不受用量列表搜索影响。
- JSON 色板导入/导出；项目 JSON 保存/加载。项目包含完整色板、尺寸、格子和编辑结果；不包含原始图片与视图缩放。
- 纯图案 PNG：每格 12 px，空白格保留透明；制作 PNG：每格 24 px，完整网格、色号、坐标、用量。
- PDF 默认「整张图纸 · 单页」：根据图纸尺寸与完整用量清单自动生成页面比例，不套用 A4。图纸、色号、坐标和用量使用矢量绘制，放大仍清晰；中文标题使用独立小幅画布嵌入。同一页包含图纸和全部所需色号数量。
- PDF 也可选「A4 分页 · 实物大小打印」：支持 3/5/7 mm 每格，先打印用量清单，再分页图纸，附全局坐标、拼接行列、上下左右位置、页码和 60 mm 校准线。请选择「实际大小 / 100%」打印。
- 分享 HTML：把当前编辑后的格子、完整色板、查看界面和用量计算嵌入单个 `.html` 文件。发给朋友后保存到电脑，用 Chrome / Edge 直接打开即可；无需 Node.js、本地服务器、网站授权或联网。支持缩放、拖动、触控双指缩放、网格/色号/坐标切换、全部所需色号与数量、点击色号高亮；可下载项目 JSON 回到工具继续编辑。不包含原始照片。
- 简体中文桌面三栏布局；移动端通过顶部标签折叠面板；所有转换和导出独立于预览缩放。

调整参数后点击「生成拼豆图纸」应用；生成会替换当前格子，原编辑可撤销恢复。加载只含格子数据的项目后，继续编辑/导出不需要原图；重新转换需要重新上传图片。

## 色板与来源

内置 **Mard · 221 色对照**，采集于 2026-10-07，来自用户提供的 [Pindou Online 色号页](https://www.pindou.online/colors)。这是第三方对照数据，不声称是品牌官方发布，实物可能存在显示或批次色差。221 个编号和 HEX 都直接取自页面，没有编造官方色号。

另有 **通用示例 · 32 色**，`S01`–`S32` 为工具自定义示例编号，与品牌官方编号无关。

色板 JSON 示例（也接受仅含颜色的数组）：

```json
{
  "name": "我的真实色板",
  "description": "来源说明",
  "colors": [
    { "code": "X01", "name": "白色", "hex": "#FFFFFF" },
    { "code": "X02", "name": "黑色", "hex": "#000000" }
  ]
}
```

每个编号必须唯一，最多 12 位字母、数字、下划线或短横线；HEX 必须为 `#RRGGBB`，色板最多 1000 色。导入后选中该色板，再点击生成应用到当前图片。绘制时可以加入转换阶段未使用的颜色，因此编辑后的实际色数可能超过生成上限。

`scripts/import-mard.mjs` 是开发者更新数据用的脚本，需要联网；普通使用无需联网。脚本校验 221 个唯一编号，页面结构或总数变化时停止写入，避免静默导入错误数据。

## 代码组织

```text
src/core/types.ts        图纸、色板、参数的类型和上限
src/core/sampling.ts     图片校验、裁剪采样、Worker 调度
src/core/photo.ts        照片区域平均、去边缘背景、碎色简化、对比与透明合成
src/core/color.ts        sRGB → OKLab、感知色差、文字颜色
src/core/quantize.ts     有限色板匹配、限色与抖动
src/workers/             转换后台线程，进度和错误返回
src/core/pattern.ts      尺寸校验、统计、替色、项目格式
src/core/render.ts       共享图纸渲染，从格子数据读取
src/core/export.ts       PNG 和分页 PDF，从格子重新生成
src/hooks/useHistory.ts  原子编辑历史
src/components/         画布手势、裁剪和弹窗
src/data/mard.json       可复核的第三方色板快照
```

`Pattern.cells` 是唯一图纸数据来源。颜色编号或 `null` 表示每一个格子；统计、预览、编辑和导出都消费这份数据。导出不依赖屏幕截图。单页 PDF 使用矢量格子和色号，中文标题独立渲染；A4 分页 PDF 使用独立页面图像嵌入，物理尺寸由 PDF 毫米坐标确定。分享 HTML 复用主工具的图纸渲染器与用量统计函数，数据、CSS 和查看脚本内嵌，不引用外部文件。

## 验收与边界

核心测试覆盖照片区域采样、透明合成、纯色去背景、保留轮廓的简化、高细节照片限色、透明格、抖动、尺寸、替色统计、项目往返和无效色板。详细浏览器验收记录见 **VERIFICATION.md**。

图片限制 25 MB / 4000 万像素；项目 JSON 限制 15 MB。过大尺寸提供错误提示。导出制作 PNG 超过 4000 万输出像素时，在分配 Canvas 前提示使用分页 PDF，纯图案 PNG 仍可导出。处理期间禁用会改动图纸的操作，显示进度。

照片处理与限色在 Worker 中执行。照片 RGB 使用最多 32,768 个分箱，各分箱以实际均值转换为 OKLab；像素插画按精确 RGB 分组，以保留相近的已有色块。匹配到真实色板后，通过加权贪心选择有限颜色，缓存色板间距离，再进行最终映射。计算量受图纸大小和色板大小限制，不按原照片百万像素逐一搜索色板。高尺寸适合保留照片细节，也会增加实物颗数和打印页数。

已验证桌面、小窗口和手机尺寸的布局及浏览器交互。真实手机硬件、打印机纸张和色差仍需在实物上校准；PDF 附 60 mm 校准线。

## 示例图片

默认的 `public/sample-photo.jpg` 是 Don McCulley 拍摄的真实向日葵照片，保留自然庭院背景，来源为 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Sunflower_Public_Domain.jpg)，CC0 1.0。原图 5040×4000，本地示例等比例缩小至 1600×1270，仍保持连续照片色彩。来源与许可也保存在 `public/sample-photo-license.txt`。

保留的 `public/sample-cat.png` 由内置 **imagegen** 生成，透明像素插画 PNG。使用的提示词是：

> Centered coarse pixel-art orange tabby in a pale mint teacup, one yellow flower beside its ear, limited flat palette, dark navy outline, transparent background, 8% padding, no text/UI.

打开工具即自动转换真实照片，所有示例操作使用实际图纸数据。像素插画仅作为另一种输入类型的体验入口。
